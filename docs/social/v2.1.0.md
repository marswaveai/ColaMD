# ColaMD v2.1.0 Social Copy

## Chinese

ColaMD 2.1.0 已发布，这一版带来的是**标签页**。

我们做标签页的想法很简单：同一个窗口里放好几份文档，但让它们彼此不认识。每个标签自己带着内容、撤销历史、未保存状态和阅读位置，来回切换不会互相影响，也不会因为切换就替你做写盘的决定。

怎么用：

- `⌘T`，或者 File 菜单里的「新建标签页」
- **在文件列表里按住 ⌘ 点击一个文件**，它会在新标签里打开（Windows / Linux 上是 Ctrl）
- 在文件列表里右键，第一项也是「在新标签页打开」
- 点标签切换；中键点标签、或者 `⌘W`，关掉这一份
- 只有一个文档的时候，界面上不会出现标签栏，和以前完全一样

标签页是「用完即走」的：关掉应用不会记住这组标签，也没有固定标签、标签分组、跨窗口拖拽这类工作区功能。它解决的是「手边几个文件来回看」这件事，不是把写东西变成管理项目。

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

## English

ColaMD 2.1.0 is out, and it brings **tabs**.

The idea behind them is simple: keep several documents in one window, and let each one stay a stranger to the others. A tab carries its own content, undo history, unsaved state and reading position, so switching back and forth never mixes them up, and switching never makes a save decision for you.

How to use them:

- `⌘T`, or File → New Tab
- **Hold ⌘ and click a file in the file list** to open it in a tab of its own (Ctrl on Windows and Linux)
- Right-click a file in the list: the first item is Open in New Tab
- Click a tab to switch, middle-click it or press `⌘W` to close that one
- With a single document there is no tab strip at all, exactly as before

Tabs are meant to be disposable: quitting does not remember the set, and there are no pinned tabs, tab groups or dragging tabs between windows. They solve "a few files at hand", not turning writing into project management.
