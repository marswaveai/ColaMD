# ColaMD v2.0.4 Social Copy

## Chinese

ColaMD 2.0.4 已发布，这一版主要修问题。

- **撤销不再跨文档**：同一窗口切换文件后按撤销，不会再把你带回上一篇文档的内容，也不会因此把上一篇误写进当前文件
- **复制不再多空行**：复制到微信、钉钉等聊天工具时，不再多出一堆空行
- **PDF 导出修复**：导出时不再把更新提示等浮层当成正文
- **源码模式修复**：源码模式与文件面板同时打开时不再横向溢出
- **新增**：鼠标移到文档标题上，右侧出现文件夹按钮，一键在 Finder 或资源管理器中定位当前文件
- **移除**：标题栏那个 Agent 状态小圆点。它只能根据文件变化的时间间隔猜测，而内容实时更新本身已经说明了一切
- **输入更轻**：大纲面板隐藏时不再每帧重建，长文档打字负担更小

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

https://github.com/marswaveai/ColaMD/releases/tag/v2.0.4

## English

ColaMD 2.0.4 is out, mostly a fix release.

- Undo can no longer cross documents: after switching files in the same window, undo will not restore the previous document's content, and cannot write it back to the current file
- Copying no longer inserts blank lines in chat apps such as WeChat and DingTalk
- PDF export no longer captures app overlays as document content
- Source mode no longer overflows horizontally when the file panel is open
- New: hover the document title for a folder button that reveals the file in Finder or File Explorer
- Removed: the titlebar agent status dot. It could only guess from file-change timing, while the live content update already says everything
- Lighter typing: the hidden outline panel is no longer rebuilt on every frame

Free, open source, local first, for macOS, Windows and Linux. In-app updates are announced automatically, or download directly:

https://github.com/marswaveai/ColaMD/releases/tag/v2.0.4
