# ColaMD v2.8.0 Social Copy

发布方式：正式版。

## 主文案（直接发）

ColaMD 2.8.0 发布，重写列表编辑交互，补齐有序列表编号、缩进与光标体验。

- 列表只在标记后敲空格时触发，敲 `1.` 或 `-` 后按 Tab 不再误触发列表格式；隔着空行另起列表从 `1.` 独立计数。
- 删除或替换首项时下方序号即时归 `1.` 且不丢格式，非首项首字前退格直接合并到上一项，撤销一步完整还原。
- Tab 与 Shift+Tab 升降级时整棵子树同步联动，首项不误推成代码块，支持多行选区批量缩进与 Shift+Enter 项内软换行。
- 有序前缀整体保护，点击和左右键不落进数字中间；长句折行悬挂缩进对齐正文，退出列表后光标立刻回到左缘。
- 修复普通段落下方敲 `-` 被误判成二级标题下划线、以及同行出现双圆点的问题。
- 围栏代码块、HTML 块与折行年份数字不再被误排号或锁光标，同步修复雅致与羊皮纸主题下引用内列表缩进。

https://github.com/marswaveai/ColaMD/releases/tag/v2.8.0

## English

ColaMD 2.8.0 is out with a rewritten list editing engine for ordered and unordered lists.

- Lists trigger only on a space after the marker, so pressing Tab after `1.` or `-` no longer creates a list; lists separated by a blank line start fresh at `1.`.
- Deleting or replacing the first ordered item renumbers following items back to `1.` without losing list styling, Backspace on a subsequent item merges into the previous one, and Undo restores everything in one step.
- Tab and Shift+Tab move the entire nested subtree together while preventing the first item from becoming a code block, with multi-line selection indent and Shift+Enter soft line breaks.
- Ordered prefixes act as atomic ranges so clicks and arrow keys stay in item text; wrapped lines use hanging indentation, and exiting a list places the cursor back at the left edge immediately.
- Typing `-` below a paragraph no longer turns the line into a Setext heading, and inline `- - ` no longer renders double bullets.
- Fenced code blocks, HTML blocks, and wrapped year numbers like `2026.` are never renumbered or cursor-locked, and quoted list indentation is fixed in the Elegant and Sepia themes.
