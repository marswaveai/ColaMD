## English

ColaMD 2.1.2 is out. This one only takes things away.

ColaMD is an immersive canvas, so the shell has to stay out of the way. Both changes are in the tab strip:

- **The first tab now sits flush with the window edge**: there used to be a small gap on the left that read as a misalignment
- **The theme colour line on the active tab is gone**: it picked up whatever accent the theme carried, which was too loud for a quiet window. The paper colour and the open bottom edge already say which tab is active

Free, open source, local first, on macOS, Windows and Linux. The app offers updates on its own, or download directly:
