# ColaMD v2.8.1 Social Copy

发布方式：正式版（修复版）。

## 主文案（直接发）

ColaMD 2.8.1 发布，表格在渲染模式下直接改，点格子不再露出源码。

- 点进格子就改字，拖选复制带上加粗、颜色、行内代码与公式。Tab 与 Shift+Tab 在格子之间移动，⌘Enter 在当前行下方插行。
- 表格里的公式、颜色标记与高亮只在自己格子里生效，不再跨竖线把两列并成一列。
- 表格上下的隐藏空行不再被退格或前删整段吃掉，光标落进相邻表格，正文和表结构都不动。
- 长文档滚到后半段时，引用里的表格保留缩进，幻灯片与 PDF 分页也对得上。
- 空单元格里中文组字时点到别处，已输入的字留在原格。
- 列表里的代码块按上下键不再被当成标题前缀跳过，零宽公式点击不再报错。

https://github.com/marswaveai/ColaMD/releases/tag/v2.8.1

## English

ColaMD 2.8.1 is out with in-place table editing in rendered mode.

- Click a cell and type, no more whole-table source view. Dragging across cells copies the text with bold, colors, inline code and math intact. Tab and Shift+Tab move between cells, Cmd+Enter inserts a row below.
- Inline math, colored spans and highlights inside a table stay inside their own cell, instead of pairing across the column separators.
- The hidden blank line around a table is no longer removed by Backspace or Delete, which used to swallow body text or break the table; the caret now moves into the neighboring table.
- Tables inside quotes keep their indentation in long documents, and slideshow and PDF pagination line up again.
- Text typed with an IME in an empty cell stays in that cell when you click elsewhere.
- Arrow keys no longer skip code lines in lists as if they were heading prefixes, and clicking a zero-width formula no longer throws.

https://github.com/marswaveai/ColaMD/releases/tag/v2.8.1
