# ColaMD v2.8.2 Social Copy

发布方式：正式版（修复版）。

## 主文案（直接发）

ColaMD 2.8.2 发布，支持文件列表右键重命名，补齐有序列表起始号与续行缩进，修复源码模式定位等几处细节。

- 双击有序列表的序号可直接修改起始数字，同组后续编号自动顺延。在列表中间插入普通行后按 Tab 对齐上一项正文并接回编号，Shift+Tab 或行首退格一次退回顶格。
- 侧栏文件列表支持右键重命名，改名后标签页标题、路径与当前编辑状态同步更新。
- 修复源码模式的大纲定位与查找滚动，长段落自动折行时点击大纲、滚动高亮和查找命中都会滚到真实位置。
- 修复引用块内分段的空 `>` 行露出原始 `>` 符号的问题。
- 修复 Word 导出时列表项以表格或代码块开头导致段落顺序颠倒的问题，以及网页试用页缺少排版样式的问题。

https://github.com/marswaveai/ColaMD/releases/tag/v2.8.2

## English

ColaMD 2.8.2 is out with right-click file renaming, ordered list start number editing and continuation indentation, plus fixes for source mode navigation and exports.

- Double-click an ordered list number to change its starting value, with following items renumbering in sequence. Pressing Tab on a plain line inside a list aligns it to the previous item and reconnects the numbering, while Shift+Tab or Backspace returns it cleanly to column 0.
- Right-click any file in the sidebar to rename it in place, keeping the open tab title, path and editor state in sync.
- Source mode outline clicks, scroll highlight sync and find matches now measure wrapped lines accurately and scroll to the real position.
- Blank `>` lines separating paragraphs inside a blockquote no longer show a raw `>` marker.
- Fixed Word export putting list item paragraphs ahead of leading tables or code blocks, and restored missing preview styles on the web playground page.

https://github.com/marswaveai/ColaMD/releases/tag/v2.8.2
