## Chinese

ColaMD 2.7.10 发布。这一版改的都是打字时的那几下：`#` 什么时候变标题，回车和退格做什么，列表缩进多宽，序号什么颜色。

**`#` 打出来还只是 `#`。** 以前敲一个 `#`，整行立刻变标题，字号跳一下，`#` 自己还被藏起来，接着打字母又退回段落。CommonMark 把孤立的 `#` 当成空标题，可人是还没决定要写什么。现在 `#` 后面跟着空格才算标题。单独一个 `>` 同理，保持原样不藏。

**链接不再吞掉后半行。** 打 `https://example.com/a：后面还有字`，全角冒号之后的中文被一起算进链接，整段染成链接色，后面的格式也就丢了。链接现在停在第一个中文字符或全角标点之前。

**回车和退格退回 CodeMirror 自己的命令。** 上一版这两下是手写的，退出列表、行首退格、标题退回段落各写了一处例外，凡是没想到的动作就丢格式。现在续列表用官方的 `insertNewlineContinueMarkupCommand`，关掉「空条目上方插空行」，跟 Obsidian 一样直接退出列表；退格用 `deleteMarkupBackward`。行首退格先拆结构：少一级缩进、拆掉标记、标题变回段落，最后才把两行粘起来。

**列表缩进收窄一半。** 以前行首的空格和样式表各给一份缩进，二级多 8px、三级多 16px，有序列表还比无序多 4px。现在行首空格在渲染模式藏起来，缩进只由一处给：圆点落在 24 / 48 / 72px，有序无序对齐。

**序号和列表文字都用正文色。** 上一版只改了圆点，序号还是灰的，一级列表里 3 和 9 甚至是黑的。根因是高亮层把序号当成标记字符压灰，那道 span 嵌在序号元素里面，只给外层设色盖不住。

**Word 导出的代码块不再乱码。** 字体以前写死成 Menlo，Windows 上没有这个字体，找不到就整段替换成符号。现在按平台选字体，代码逐行输出、行间是真换行，段落左对齐，不再被两端对齐拉成「键在左边、值在右边」。

另外几处：表格单元格里的行内公式画成公式了，导出的 HTML 也不再把这层编辑器外壳带出去；多位序号缩进成子列表时，光标不再跑回行尾；README 里补上了 Homebrew 的安装方式，社区一直在维护那个 cask。

## English

ColaMD 2.7.10 is out. This release is about how typing feels.

A lone `#` now stays a plain `#`. It used to turn the whole line into a heading the moment you pressed the key, and typing the first letter dropped it back to a paragraph. A heading needs the space after the `#` now. Same for a lone `>`.

Links no longer swallow the rest of the line. Typing a URL followed by a full-width colon used to pull the Chinese text behind it into the link and paint it in link color. The link now stops before the first CJK character or full-width punctuation.

Enter and Backspace go back to CodeMirror's own commands. The previous version hand-rolled both and lost formatting for anything the special cases did not cover. List indentation is half as wide as before, and list numbers finally use the body text color.

Word export no longer garbles code blocks on Windows.
