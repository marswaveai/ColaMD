# ColaMD v2.0.6 Social Copy

## Chinese

ColaMD 2.0.6 已发布，这一版修的是标题栏上的三件小事。

- **「打开所在文件夹」修好了**：鼠标移到文档名上，右侧浮现文件夹按钮，点击即可在 Finder 或资源管理器中定位当前文档。这个按钮从 2.0.4 起就在，但一次代码重构把它的接线删掉了，所以一直点不出来
- **提示标签不再「穿透」**：悬停标题栏按钮时，提示标签以前被画在正文下面，还带淡入，看起来像半透明压在文字上。现在它完全画在正文之上，并且立即完全不透明
- **右上角按钮对齐**：三个按钮的右侧边距和上边距对齐，视觉上更整齐

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

https://github.com/marswaveai/ColaMD/releases/tag/v2.0.6

## English

ColaMD 2.0.6 is out with three small titlebar fixes.

- Reveal in file manager works again: hover the document title and a folder button appears next to it, locating the current file in Finder or File Explorer. The button has been in the titlebar since 2.0.4, but a refactor deleted its wiring, so it could never be clicked
- Tooltips no longer show through: hovering a titlebar control used to draw the label under the document text, with a fade on top, which read as a translucent label. It now paints above the document and appears at full opacity immediately
- Top-right controls are aligned: the three buttons now keep the same margin on the right as on the top

Free, open source, local first, available on macOS, Windows and Linux. The app updates itself, or download directly:

https://github.com/marswaveai/ColaMD/releases/tag/v2.0.6
