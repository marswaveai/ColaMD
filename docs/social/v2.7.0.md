## Chinese

ColaMD 2.7.0 换掉了编辑器的内核，先作为预发布版放出来。你现在装的版本不会被自动更新到它，想试就手动下载。

**为什么要重写整个内核**：我们希望十年后你还能用 ColaMD 打开今天写的笔记，那就不能让你的内容依赖某个软件内部的数据结构。

以前 ColaMD 打开一个文件，会先把内容解析成自己内部的一份副本，保存时再从那份副本重新生成文件。于是你从没碰过的字符也会被改写：表格的分隔行被压缩、`*` `$` `_` 被加上反斜杠、有些加粗会变成一串看不懂的字。

现在编辑器里存的就是文件的字节，渲染只是叠在字节上面的一层装饰。你打开什么样，保存就还是什么样。文件是唯一的真相，ColaMD 只是让它看起来更舒服的那一层。

这一版你会感觉到的变化：

- **长文档导出不再只有一屏**：以前导出 PDF 或图片，只印出屏幕上看得见的那一段，后面的内容全丢
- **补齐了一批功能**：图片、链接、脚注（悬停看内容）、HTML 片段、Mermaid 图表、代码块的语法高亮和复制按钮、列表回车自动续行、Tab 缩进
- **公式**：点击公式直接就地编辑，弹层去掉了；`$349` 这种价格不会再被当成公式
- **复制是干净的**：选一段文字粘到别处，出来的是段落和格式，不带 markdown 标记，也不会被拆成好几段
- **观感**：和以前基本一致，个别间距有几个像素的差别

这是一次内核重写，改动面很大。如果你遇到显示异常，或者觉得哪里和以前不一样，欢迎开一个 Issue 说一声，附上截图，方便的话连文件一起（脱敏后）。想先用回老版本，2.6.0 的安装包还在 Release 页。

免费、开源，文件永远是最新的。

## English

ColaMD 2.7.0 replaces the editor core, and it goes out as a pre-release first. Your current install will not be updated to it automatically; download it by hand if you want to try it.

**Why the whole core was worth rewriting**: we want you to still be able to open a note you write today ten years from now, which means your content cannot depend on a data structure that lives inside one program.

ColaMD used to parse a file into an internal copy when it opened it, then regenerate the file from that copy on save. Characters you never touched came back changed: table delimiter rows were compressed, `*`, `$` and `_` were given backslashes, and some bold text turned into a string of characters nobody could read.

The editor now holds the file's bytes, and rendering is a layer drawn on top of them. What you open is what you save. The file is the only truth; ColaMD is just the layer that makes it comfortable to look at.

What you will notice in this version:

- **Long documents export whole**: exporting to PDF or an image used to print only the part of the document that happened to be on screen, and drop the rest
- **A batch of features came back**: images, links, footnotes (hover to read them), inline HTML, Mermaid diagrams, code highlighting and copy buttons, list continuation on Enter, Tab indentation
- **Formulas**: click one to edit it in place, the popup editor is gone, and prices like `$349` are no longer treated as formulas
- **Copy is clean**: select text and paste it elsewhere and you get paragraphs and formatting, with no Markdown markers and no broken-up paragraphs
- **Looks**: essentially the same as before, a few spacings differ by a couple of pixels

This is a core rewrite and the surface area is large. If you hit a rendering problem, or something feels different from before, please open an issue with a screenshot, and the file too if you can (redacted). To go back to the previous version, 2.6.0 is still on the releases page.
