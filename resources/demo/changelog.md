# ColaMD Changelog

欢迎来到 ColaMD 的**可玩 changelog**。左侧面板列出的就是本目录的文件——点击切换，每个文件演示一组功能。这是演示副本，玩坏了随时可以从仓库恢复。

---

## v2.0.1 · Universal macOS build

- **macOS Universal**：提供同时支持 Apple silicon 与 Intel 的通用版 `.dmg` 和 `.zip`
- **主题恢复修复**：新窗口正确继承自定义主题
- **Mermaid 稳定性修复**：渲染器重建时不会遗留永久等待的请求
- **Windows 更新修复**：统一安装包资产名称，避免更新下载 404

## v2.0.0 · 1000 Stars

- **保存状态提示**：标题栏实时显示「未保存 / 已保存」，自动保存完成后自动淡出
- **文档内锚点跳转**：点击 `[文字](#标题)` 链接平滑滚动到对应标题，支持中文、URL 编码和重复标题
- **最近文件与会话还原**：「文件 → 最近打开」列出最近 10 篇文档；启动时自动恢复上次编辑的文档，可在菜单中关闭
- **编辑器字体设置**：「视图 → 编辑器字体…」可选系统全部字体与字号，实时预览；优先级为 用户设置 > 主题 > 默认
- **多窗口**：「文件 → 新建窗口」打开独立编辑窗口，每个窗口独立保存状态与关闭保护
- **Mermaid 回归**：流程图、时序图重新渲染，按代码块底色自动选择配色，点击图表可编辑源码
- **主题菜单选中态**：当前主题在菜单中带勾选标记，自定义主题同样支持
- **细节修复**：源码模式内容居中、代码块复制按钮、窗口无响应时仍可正常退出

## v1.9.0 · 导出与大纲

- **保存保护**：已打开的文档停止输入 1 秒后自动保存；切换文件时先保存当前内容；关闭窗口或退出应用时会再次确认，写入失败则保留窗口和未保存内容
- **新版本说明**：每次安装新版本后的首次启动自动打开本页，之后不再重复打扰
- **阅读页图片导出**：文件菜单可按电脑或手机阅读页导出 PNG；长文连续生成多张页面图片，最后一页按内容裁短
- **Word 导出**：文件菜单可将当前文档导出为 `.docx`，保留常见标题、列表、表格、链接、代码块和本地图片
- **主题化 PDF**：PDF 导出使用当前主题的整页背景，保留统一的阅读边距
- **侧栏大纲**：打开文件面板后切换到「大纲」，点击标题可在所见即所得或源码模式中跳转；大纲模式只显示文档导航
- **启动优化**：导出组件按需加载，减少日常启动需要解析的主进程代码

## v1.8.2 · Themes

- **12 个内置主题**：6 个浅色和 6 个深色主题，均可从「主题」菜单切换
- **自定义主题目录**：内置主题以独立 CSS 文件保存在仓库 `themes/` 目录，可作为自定义主题起点
- **主题对比度检查**：语义色 token 与自动检查防止自定义主题出现不可读文字

## v1.8.1 · 启动体验与 macOS 图标视觉刷新

- **macOS 应用图标**：中央 Cola 红色主体改为黄金分割比例的正方形
- **图标层次**：统一透明圆角、阴影、渐变和多尺寸 ICNS 资源
- **视觉收敛**：保留单一波浪线，移除多余装饰弧线
- **稳定性修复**：移除 Mermaid 图表渲染，代码块恢复为原生编辑体验
- **无权限启动**：首次打开默认展示内置示例，不再扫描用户的「文稿」目录
- **双语语法文档**：Help 根据系统语言自动显示对应版本

## v1.8.0 · 图片路径保存修复与编辑体验完善

这一版继续收敛社区反馈，并修复本地图片路径在显示和保存之间的边界问题：

- **图片路径可移植保存**：编辑器渲染时使用 `file://` URL，保存 Markdown 时恢复为相对于文档的路径
- **HTML 图片路径同步修复**：原生 `<img src="...">` 也不会把绝对 `file://` 路径写回源文件
- **社区 Issue 收尾**：代码块复制、HTML 图片、Windows 路径、VS Code 未保存内容和格式编辑均已完成

## v1.7.4 · 社区反馈与 Markdown 工作流

昨天发布 v1.7.3 后，我们收到了社区的反馈。这一版带来：

- **源码模式**：在所见即所得和原始 Markdown 之间快速切换
- **文件面板完善**：支持轻量目录浏览；没有打开文件时默认展示「文稿」目录
- **HTML 导出**：将当前文档导出为独立 HTML 文件
- **Windows 图片路径**：修复 Windows 本地图片显示
- **VS Code 集成 MVP**：从 VS Code 将当前 Markdown 文件打开到 ColaMD

## 模拟 Agent

打开终端，对当前目录做点改动，窗口会实时响应：

```bash
echo '- [ ] 这是 Agent 刚写入的任务' >> tasks.md
echo '# 全新文件' > new.md
```

第二行会**实时**出现在左侧面板里——文件面板和内容一起动。

Markdown 语法请使用 Help 中的主入口，内容会根据系统语言自动选择。
